# CamLock — แอปตู้เช่ากล้องอัตโนมัติ

เว็บแอปสำหรับนักศึกษาเช่ากล้องจากตู้ล็อกเกอร์ ไม่ต้องมีคนเฝ้า
วิชา CPE23367 · มหาวิทยาลัยศรีปทุม

- **ใช้งาน:** https://benharry12.github.io/camlock-app/
- **Firmware (ESP32):** https://github.com/BENHarry12/camlock-firmware

## ภาพรวม

```
มือถือนักศึกษา ── HTTPS ──> ThingsBoard Cloud ── MQTT ──> ESP32 (ตู้)
   index.html       RPC + อ่าน telemetry
```

เป็นไฟล์ HTML/CSS/JavaScript ไฟล์เดียว ไม่มีขั้นตอน build ฝากไว้บน GitHub Pages
ข้อมูลสมาชิก กล้อง และการเช่า เก็บอยู่ในบอร์ด ESP32 แอปส่งคำสั่งผ่าน ThingsBoard RPC
และอ่านสถานะประตู/กลอนจาก telemetry ล่าสุด

### หน้าจอ

**นักศึกษา:** สมัครด้วยชื่อผู้ใช้ (รหัสนักศึกษาไม่บังคับ) · ยืนยันตัวตน (ถ่ายรูปบัตร + รูปหน้า ผู้ดูแลอนุมัติ) · หน้าแรก (สถานะตู้สด) · เลือกกล้อง · เลือกชั่วโมงและดูค่าใช้จ่าย
· ชำระเงินด้วย QR พร้อมเพย์ (ใส่ยอดให้อัตโนมัติ) · เปิดตู้ (โมเดลตู้ 3 มิติจำลองตามสถานะจริง ลากหมุนดูได้ ปุ่ม "ล็อกตู้")
· กำลังเช่า (นับถอยหลัง ต่อเวลา คืนกล้อง) · ประวัติและกราฟรายเดือน · บัญชี

**ผู้ดูแล:** ตรวจการยืนยันตัวตน · ภาพรวม (ยืนยันเงิน เกินกำหนด รอคืนมัดจำ ปลดล็อกทันที บันทึกการทำงาน) · การเช่าทั้งหมด
· จัดการกล้อง · จัดการสมาชิก · ตั้งค่า (ข้อมูลตู้ พร้อมเพย์ เวลาปลดล็อก QR หน้าตู้)

## ตั้งค่า ThingsBoard (ทำครั้งเดียว)

1. **Devices** → เปิดอุปกรณ์ตู้ (ตัวที่ใช้ Access token ใน firmware) → **Copy device ID**
2. **Customers** → เพิ่ม Customer ชื่อ `CamLock App`
3. กลับไปที่อุปกรณ์ → **Assign to customer** → เลือก `CamLock App`
4. **Customers** → `CamLock App` → **Manage users** → เพิ่มผู้ใช้ เช่น `app@camlock.example` → ตั้งรหัสผ่าน (Activate)
5. แก้ไฟล์ `config.js`

```js
window.CAMLOCK_CONFIG = {
  tbUrl: 'https://thingsboard.cloud',
  deviceId: '<Device ID จากข้อ 1>',
  tbUsername: 'app@camlock.example',
  tbPassword: '<รหัสผ่านจากข้อ 4>',
  appUrl: 'https://benharry12.github.io/camlock-app/'
};
```

6. Commit แล้วรอ GitHub Pages อัปเดต (1–2 นาที)

> **สำคัญ:** `config.js` อยู่บนเว็บสาธารณะ ใครก็เปิดอ่านได้ ให้ใช้ **Customer user ที่เห็นแค่อุปกรณ์ตู้นี้** เท่านั้น
> ห้ามใช้บัญชี Tenant administrator ของตัวเอง คนที่ได้บัญชีนี้ไปยังเปิดตู้ไม่ได้
> เพราะทุกคำสั่งต้องมี token จากการเข้าสู่ระบบของแอปที่บอร์ดตรวจเอง

## ฝากเว็บบน GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `/ (root)` → Save

## เข้าใช้งานครั้งแรก

1. เปิดแอป เข้าระบบ **admin / 1234** → แท็บ **ตั้งค่า** → **เปลี่ยนรหัสผ่านของฉัน** ทันที
2. ใส่เลขพร้อมเพย์ของร้าน
3. แท็บ **กล้อง** แก้/ลบกล้องตัวอย่าง ใส่กล้องจริง (สูงสุด 8 ตัว)
4. ตั้งค่า → **QR หน้าตู้** → พิมพ์ติดหน้าตู้

## ข้อจำกัด

- **ระบบเช็คยอดเงินเข้าบัญชีเองไม่ได้** ผู้ดูแลต้องดูแอปธนาคารแล้วกด "ได้รับเงิน"
- ตู้ออฟไลน์ = เปิดตู้จากแอปไม่ได้ ต้องมีกุญแจสำรองเชิงกล
- รองรับสมาชิก 30 คน กล้อง 8 ตัว ประวัติ 40 รายการ (ตามหน่วยความจำของ ESP32)

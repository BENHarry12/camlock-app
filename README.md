# CamLock — ตู้เช่ากล้องอัตโนมัติ (Application)

แอปพลิเคชันสำหรับผู้เช่ากล้อง ตั้งแต่เลือกกล้อง จ่ายเงิน สแกน QR เปิดตู้ ไปจนถึงคืนกล้อง

> **วิชา CPE23367 · มหาวิทยาลัยศรีปทุม**

**เปิดใช้งานได้ที่** → https://benharry12.github.io/camlock-app/

---

## หน้าจอในระบบ

ออกแบบไว้ 16 หน้าจอ ขนาดอ้างอิง 390 × 844 px (iPhone)

| # | หน้าจอ | หน้าที่ |
|---|---|---|
| 1 | เข้าสู่ระบบ | ใช้รหัสนักศึกษา ไม่ต้องสร้างรหัสใหม่ |
| 2 | หน้าแรก | เห็นตู้ที่ใกล้ที่สุดและจำนวนกล้องว่างทันที |
| 3 | เลือกกล้อง | มีสเปกและราคาต่อชั่วโมงครบทุกตัว |
| 4 | รายละเอียดการเช่า | เลือกชั่วโมง จุดคืน แล้วสรุปค่าใช้จ่าย |
| 5 | ยืนยันตัวตน | บัตรนักศึกษา ใบหน้า และ OTP ทำครั้งเดียว |
| 6 | ชำระเงิน | พร้อมเพย์ บัตร หรือ CamLock Wallet |
| 7 | สแกน QR | รหัสใช้ครั้งเดียว หมดอายุใน 5 นาที |
| 8 | กำลังเช่าอยู่ | นับถอยหลัง และต่อเวลาได้ |
| 9 | ประวัติการเช่า | สถิติรายเดือนและรายการย้อนหลัง |
| 10 | โปรไฟล์ | บัญชี ความปลอดภัย การใช้งาน |

## หลักการออกแบบ

**เห็นสถานะก่อนเสมอ** — คำถามแรกของทุกคนคือ "ตอนนี้มีกล้องว่างไหม" เราเลยเอาคำตอบขึ้นบนสุดของหน้าแรก

**หนึ่งหน้า หนึ่งปุ่มหลัก** — ทุกหน้ามีปุ่มใหญ่สีเข้มปุ่มเดียวที่กดต่อไปได้ กดผิดยาก และอยู่ตรงที่นิ้วโป้งเอื้อมถึง

**ทุกสีมีคำกำกับ** — สถานะว่าง เช่าอยู่ สำเร็จ มีตัวหนังสือกำกับเสมอ คนตาบอดสีก็อ่านรู้เรื่อง

**บอกความจริงเรื่องเงิน** — หน้ามัดจำเขียนชัดว่าเป็นการกันวงเงิน ไม่ได้ตัดเงินจริง คืนให้ภายใน 1–3 วันทำการ

## เบื้องหลังการสแกน QR หนึ่งครั้ง

| ขั้น | เกิดอะไรขึ้น |
|---|---|
| 1 | แอปอ่าน QR — รหัสใช้ครั้งเดียว หมดอายุใน 5 นาที |
| 2 | ตรวจสิทธิ์การจอง — เช็กว่าจ่ายเงินแล้วจริง และเป็นช่องของคนนี้ |
| 3 | ส่งคำสั่ง MQTT ลงมาที่ตู้ |
| 4 | ESP32 สั่งขา GPIO26 เป็น HIGH |
| 5 | รีเลย์ทำงาน กลอนเปิดค้าง 3 วินาที |
| 6 | รีดสวิตช์ยืนยันว่าประตูเปิดแล้ว ส่ง telemetry กลับขึ้นคลาวด์ |

ทั้งหมดใช้เวลาไม่เกินสองวินาที

## เทคโนโลยีที่ใช้

- **HTML / CSS / JavaScript** ไฟล์เดียวจบ ไม่ต้องติดตั้งอะไร
- **ฟอนต์ฝังในไฟล์** เปิดได้เหมือนกันทุกเครื่อง ไม่ต้องต่อเน็ตโหลดฟอนต์
- **ThingsBoard** รับส่งคำสั่งและเก็บ telemetry จากตู้
- **GitHub Pages** สำหรับ deploy

## รันในเครื่องตัวเอง

ไม่ต้อง build ไม่ต้องติดตั้ง dependency — เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย

```bash
git clone https://github.com/BENHarry12/camlock-app.git
cd CAMLOCK-APP
open index.html
```
